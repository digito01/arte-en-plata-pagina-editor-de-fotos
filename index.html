¿Cómo se usa?

  1. Sube las fotos (todas juntas).
  2. Deja la limpieza automática activada: borra “PM 298”, “Antes/Ahora” y, si quieres, fechas o códigos, rellenando el fondo.
  3. Elige el logo y ubícalo arrastrándolo.
  4. Ajusta el recorte con números o arrastrando las líneas ✂.
  5. Pulsa Procesar todas y revisa las marcadas con ⚠.
  6. En la revisión, Enter pasa a la siguiente foto. Con Borrar área dibujas un recuadro para borrar algo que no se detectó.
  7. Descarga el ZIP con todas las fotos.
